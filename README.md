# CalcularIMC
Este é um projeto simples de uma calculadora de IMC (Índice de Massa Corporal).

Funcionalidades

Inserir peso e altura;

Calcular o IMC;

Mostrar a classificação do resultado;

Validar se os campos foram preenchidos.

Tecnologias utilizadas

HTML

CSS

JavaScript

Como utilizar

Informe seu peso;

Informe sua altura;

Clique no botão Enviar;

O sistema calculará o seu IMC e mostrará a classificação.

Fórmula do IMC

O cálculo é realizado da seguinte forma:

IMC = peso / altura²

Projeto desenvolvido para praticar JavaScript e manipulação de formulários.
